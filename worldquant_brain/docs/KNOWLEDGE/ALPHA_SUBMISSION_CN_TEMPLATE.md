# Alpha提交中文描述模板 Skill

## 触发条件
- 创建新Alpha时
- 准备提交Alpha时
- 用户要求生成Alpha描述时

## 模板格式

每个Alpha提交时必须包含以下三段中文描述，每段至少100字：

### Idea (核心思想)
描述这个Alpha在捕捉什么样的市场现象或定价偏差。
- 市场现象/定价偏差描述
- 信号方向与逻辑链条
- 为什么当前市场环境下该信号应有效

### Rationale for data used (数据使用理由)
解释为什么选择这个数据集和字段。
- 数据集全称与来源
- 所选字段的定义与含义
- 数据覆盖范围（股票数/时间跨度）
- 为什么该数据适合捕捉目标信号

### Rationale for operators used (算子使用理由)
解释算子链的逻辑，从内到外逐层说明。
- 算子链的逐层解释（从内到外）
- 每层算子的目的与效果
- 为什么这个算子顺序是合理的
- 与替代算子的对比（为什么选A不选B）

## 示例

### shortinterest3 max_loan_rate 示例

**表达式**: `zscore(-ts_max(vec_max(max_loan_rate), 22))`

#### Idea
该Alpha捕捉证券借贷市场中极端做空成本所预示的股价反弹机会。核心逻辑链条为：当一只股票的最高借贷利率在近期达到极端高位时，说明该股票经历了严重的做空拥挤——大量投资者借入该股票卖出，推动借贷利率飙升。在市场有效理论下，如此高的做空成本是不可持续的：空头需要支付高昂的日息来维持仓位，一旦股价不再下跌或出现正面催化剂（如财报超预期、行业利好），空头将被迫回补仓位，产生买入压力推动股价上涨。该信号本质上捕捉的是"空头挤压（Short Squeeze）"前的定价异常——做空成本越高，空头回补的动力越强，未来上涨概率越大。

#### Rationale for data used
本次使用shortinterest3（证券借贷洞察数据）数据集，数据来源于全球证券借贷市场实时交易记录，由多个主要经纪商和托管银行提供。所选字段为max_loan_rate（最高借贷利率），代表证券借贷市场中各借出方要求的最高年化利率，即做空该股票的最大成本。该数据集覆盖所有TOP3000股票（覆盖率100%），日频更新，能够实时反映市场做空情绪和借券供需状况。选择该数据集的核心理由：第一，数据覆盖范围广，确保Alpha可应用于足够多的股票；第二，数据日频更新，确保信号的时效性；第三，该数据集中绝大多数字段从未被任何用户用于Alpha构建，具有极低的生产相关性风险。

#### Rationale for operators used
算子链的处理逻辑（从内到外）：
1. vec_max：从每日多笔借贷记录中提取最高利率，聚焦于最极端的情况。最高利率代表做空的最大成本，这是空头挤压信号的核心驱动力。相比vec_avg取均值会被中间值平滑，vec_max对极端做空压力的捕捉更为敏锐。
2. ts_max(窗口=22天)：在最近22个交易日内取最大值，捕捉该周期内的极端做空压力事件。使用ts_max而非ts_mean的原因是：空头挤压恰恰由极端事件触发——只有曾经出现过极高的借贷利率，才意味着存在严重的空头拥挤，均值会掩盖这些关键的极端信号。
3. 负号(-)：将高成本信号映射为做多信号。逻辑依据：高借贷利率意味着高做空成本，而高做空成本预示着空头回补驱动的股价上涨。
4. zscore：对信号进行横截面标准化，消除不同股票间的量纲差异。zscore优于rank的关键原因是：zscore保留了原始分布的相对距离信息，极度异常的股票在zscore下会被赋予远超其他股票的分数，而rank会丢失极端值的关键信息。

## 自动生成

`api_client.py` 中的 `_generate_cn_description()` 方法会自动为每次模拟生成三段式中文描述，并通过PATCH请求写入Alpha的 `selectionDesc` 属性。

手动使用：
```python
from worldquant_brain.scripts.core import RetryableBrainClient

desc = RetryableBrainClient._generate_cn_description(
    expression="zscore(-ts_max(vec_max(max_loan_rate), 22))",
    dataset="shortinterest3",
    result={"sharpe": 2.02}
)
print(desc)
```
